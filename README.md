# 水平リセット

傾いた映像や、ゆらゆら揺れるダッチアングルの動画を水平に戻し、手ぶれも抑えるブラウザ用ツールです。
インストール不要で、スマホでもパソコンでも使えます。動画はサーバーに送られず、すべて端末の中で処理されます。

![水平リセットの画面](docs/screenshot.png)

## できること

- **自動で水平を検出**：建物の輪郭や地平線などのまっすぐな線から、映像の傾きを自動で測ります。
- **揺れに追従**：全フレームで特徴点を追跡し、時間とともに変わる傾きを毎フレーム補正します。
- **手ぶれ補正**：上下左右の細かいブレも取り除きます。強さはスライダーで調整できます。
- **一定の傾きモード**：最初から最後まで同じ角度で傾いている映像は、1つの角度でまとめて補正できます。
- **フレームの扱い**：ズームして黒い余白を隠すか、ズームせずに全体を残すかを選べます。
- **MP4 で書き出し**：音声付きで書き出し、スマホの写真アプリに保存できます。

## 使い方

1. 「動画を開く」を押すか、動画を画面にドラッグ＆ドロップします。
2. 読み込むと自動で解析が始まります。解析には動画の長さとほぼ同じ時間がかかります。
3. 必要なら「微調整」で角度を合わせます。「長押しで元の映像」を押している間は、補正前の映像と見比べられます。
4. 「補正した動画を書き出す」を押し、終わったら「写真に保存」（パソコンでは「ファイルに保存」）を押します。

キーボード操作：`←` `→` で 0.1°、`Shift` + 矢印で 1°、`Space` で再生／一時停止。

### スマホの写真アプリに保存するには

- **iPhone**：共有シートが開いたら「ビデオを保存」を選びます。
- **Android**：共有メニューから Google フォトなどを選ぶか、「ダウンロード」フォルダに保存されたものを Google フォトの「デバイス内の写真」→「Download」から見られます。

## しくみ

| 処理 | 方法 |
| --- | --- |
| 水平の検出 | 構造テンソルでエッジの向きを求め、0.5° 刻みのヒストグラムのピークから傾きを推定 |
| フレーム間の動き | Shi-Tomasi のコーナー検出 ＋ ピラミッド型 Lucas–Kanade 法で特徴点を追跡し、RANSAC で回転・拡大・平行移動を推定 |
| 揺れの補正 | 速い揺れはフレーム間の回転、長い時間の水平は線の検出、と役割を分けて組み合わせ（動的計画法で外れ値を除去） |
| 手ぶれ補正 | カメラの位置の軌跡をガウス平滑化し、その差分だけ逆向きに動かす |
| 書き出し | Canvas に描画した映像を `MediaRecorder` で録画（実時間） |

外部ライブラリは使っていません。`index.html` 1つで動きます。

## 動作環境

- Chrome / Edge / Safari の最新版（パソコン・スマホ）
- Firefox でも使えますが、書き出しは WebM 形式になります（iPhone の写真アプリには保存できません）。

## 注意

- 書き出しは動画を実際の速さで再生しながら録画するため、動画の長さと同じ時間がかかります。終わるまで画面を開いたままにしてください。
- 4K の動画は、長い辺が 1920px になるよう縮小して書き出します。
- まっすぐな線がほとんどない映像では、水平の基準を決められません。その場合は最初のコマを基準にするので、「微調整」で合わせてください。

## 公開のしかた（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開きます。
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で使えるようになります。

ローカルで試すときは `index.html` をブラウザで開くだけで動きます。
